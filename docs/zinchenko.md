# Раздел Анатолия Ивановича Зинченко

Раздел состоит из страницы профиля `/zinchenko/`, пяти дочерних страниц со списками трудов и страницы для чтения PDF. Профиль и списки собраны из шести предоставленных DOCX (один файл «Информация» и пять пронумерованных списков). Десять PDF остаются оригинальными файлами: на странице есть прямая ссылка на каждый и просмотр одного выбранного файла внутри страницы.

Исходные документы находятся в `assets/zinchenko/`. Готовые данные для страниц хранятся в `data/zinchenko.php`; при открытии страниц Word-файлы не обрабатываются. После изменения DOCX или добавления PDF пересоберите данные:

```sh
php scripts/build-zinchenko-content.php
```

Для обновления нужен PHP CLI с расширениями `zip` и `dom`. Скрипт проверяет наличие всех пяти списков и порядок библиографических записей. В списке статей журналов исходного документа есть ошибка нумерации: после записи №166 напечатано №157, затем №168. На сайте показывается порядковый №167, текст записи не изменён.

После установки темы на сайт создайте страницы командой WP-CLI:

```sh
wp eval-file wp-content/themes/mbio/scripts/setup-zinchenko-pages.php
```

Повторный запуск не изменяет уже созданные страницы и их содержимое. Если путь `/zinchenko/` уже занят другой страницей, проверьте её перед запуском. Дочерним страницам назначается шаблон «Публикации учёного — Зинченко». Ссылка на профиль находится в меню «Институт».

На чистой локальной базе WordPress не хватает страниц, медиа и полей исходного сайта, поэтому возможны предупреждения в старых шаблонах темы. В новом разделе портрет не используется: его не было среди предоставленных материалов. Английская версия также не создавалась, так как тексты предоставлены на русском языке.
